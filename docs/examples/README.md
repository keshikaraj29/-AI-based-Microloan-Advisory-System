# Supplied-story demonstration

This synthetic example uses only: “I need a loan to open milk business in bengaluru of around 10000 rupees”. The applicant name is a demonstration label. No household income, existing debt, monthly business revenue/cost, disbursement or payment is supplied.

The PDF/JSON shows INR 10,000 requested, the configured default 12-month term, 12% annual demo rate and missing financial information. An EMI estimate is not loan approval or proof of affordability. Dataset prices are context and never multiplied into a personal sales forecast.

Files: [Assessment PDF](milk_business_assessment.pdf), [Full assessment JSON](milk_business_assessment.json). No example is inserted into the application database.
